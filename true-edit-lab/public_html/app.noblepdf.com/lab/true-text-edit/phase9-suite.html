True Edit fixture suite (real browser, real engine)

Runs every Phase 9 fixture through the same analysis, gating, mutation and verification code the interactive editor uses, on the hash-pinned Run #10 engine and the pinned PDF.js 3.11.174. Supported fixtures must commit and match an independently generated reference PDF (text, glyph geometry and 288 dpi rendering); blocked fixtures must fail closed for the expected reason. Fixture PDFs only: nothing is uploaded and nothing leaves this browser.
